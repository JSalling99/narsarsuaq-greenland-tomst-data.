# narsarsuaq-greenland-tomst-data.
Scriptet importerer, samler og renser TOMST-data fra Grønland indsamlet i sommeren 2026. Dataene kontrolleres for manglende værdier, ekstreme temperaturer, dublerede tidsstempler, uregelmæssige måleintervaller og pludselige temperaturændringer. Tre målinger påvirket af sensorhåndtering sættes til NA.
